# Career-preparation skill routing

Choose the narrowest skill that owns the user's current decision. Skills may hand off to one another, but should not repeat discovery already completed.

| User need | Use | Outcome | Do not use when |
|---|---|---|---|
| Discover what actually happened in a project, recover decisions, clarify contribution, or reframe an experience for a role | `pm-experience-mentor` | Evidence-backed experience story with constraints, decisions, actions, and results | The user only wants copyediting of an already-settled draft |
| Select a concept and turn a chosen experience into a persuasive job-specific essay | `pm-drama-upgrade-mentor` | Target-job interpretation, differentiated claim, focused questions, revisions, and scoring | The experience has not been recovered and no usable source evidence exists |
| Analyze multiple job descriptions for recurring capability signals and positioning changes | `job-posting-signal-analyzer` | Baseline or weekly delta of table stakes, differentiators, evidence mapping, and gaps | The user wants one company's application essay rather than market-level analysis |

## Common flows

### From market signal to application

1. `job-posting-signal-analyzer` identifies repeated hiring signals and evidence gaps.
2. `pm-experience-mentor` recovers the strongest relevant experience when the evidence is incomplete.
3. `pm-drama-upgrade-mentor` selects the application concept and develops the final job-specific narrative.

### Existing draft with a weak claim

1. If the underlying experience is clear, start with `pm-drama-upgrade-mentor`.
2. If the draft hides or confuses the user's actual contribution, temporarily route the missing section through `pm-experience-mentor` and return to the essay.

### Weekly job-market review

1. Use `job-posting-signal-analyzer` on newly created or materially changed postings.
2. Report only signal changes and actions that should alter positioning or preparation.
3. Do not rewrite resumes or essays automatically; route explicit follow-up work to the appropriate mentoring skill.

## No-skill cases

Handle directly when the request is a simple factual answer, file operation, spelling correction, or wording change that does not require experience discovery, job-market synthesis, or application strategy.
