# Output contract

Use the smallest report that supports a positioning decision.

## Baseline report

- Scope: date range, number of database records, number of JD bodies read, and role mix
- Executive signal: the 2–3 sentence market interpretation
- Priority signals: keyword, hiring meaning, observed role types, and confidence
- Positioning map: keyword → user's supporting experience → evidence strength → recommended phrasing
- Gaps: recurring signals without adequate evidence
- Actions: resume summary, portfolio, interview, and search-strategy changes
- Sources: database link and representative posting-page links

## Weekly delta

- Window and number of new or materially changed postings
- New signals
- Signals gaining or losing weight
- Stable signals worth no action
- One to three recommended changes, only when evidence justifies them
- Sources

## Evidence rules

- `High`: repeated across multiple relevant postings and supported by complete JD text
- `Medium`: repeated in a smaller sample or concentrated in one role family
- `Low`: isolated wording, incomplete JD body, or inferred from title/properties
- Separate what employers request from what the user can currently prove.
- When mapping to the user's experience, cite or name the relevant source artifact and avoid invented scope or metrics.
